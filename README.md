# Alexx Homebrew Tap

Install the [Alexx](https://alexx.app/) desktop app (macOS 13+, Apple Silicon and Intel):

```bash
brew install alexx-app/tap/alexx
```

Once the tap is added (`brew tap alexx-app/tap`), `brew install alexx` is enough.
The app updates itself; `brew upgrade --greedy` also replaces it.

`Casks/alexx.rb` is generated by the Alexx desktop release workflow. Do not edit it here.
